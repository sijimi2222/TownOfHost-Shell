# Damocles integration tests

Links actual contributor-adapted Damocles, IKiller and IUsePhantomButton sources.
Unity, game/network objects, option factory, LateTask executor and cooldown transport are substitutes.
Checks authoritative state/rolls, duplicate notifications, safe lifecycle delays, defaults, RPC payloads and non-host reception.
Does not verify native Phantom animation/button, actual lag, host migration, Vanilla rendering or UDP delivery.
Run the existing RoleDisplay/RoleOrigins suites and static ID/translation audit alongside these checks.
