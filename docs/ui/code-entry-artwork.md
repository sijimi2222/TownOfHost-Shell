# Shell コード入力画面の画像差し替え

対象バージョン：TOH-Shell v2.2.2。UIと画像は独立しています。PNGがなくても仮のパネルと元の入力・操作機能を利用できます。

## 保存先と画像仕様

ゲームの `BepInEx/config/TOH-Shell/MainMenu/CodeEntry/` に保存します。
ファイル名は下表の固定名です。ファイルの追加・置換後、コード入力画面を閉じて開き直すと再読み込みします。ゲームの再起動やDLLの再ビルドは不要です。

| ファイル | 推奨サイズ（px） | 透過 | 用途 |
|---|---:|---|---|
| `panel.png` | 1170 × 560 | 角・外周は透過可。本文を読む部分は十分な不透明度を推奨 | 中央パネル全体。設定時は仮の紫パネル・枠を置き換える |
| `illustration.png` | 325 × 380、または同じ縦横比の高解像度 | 推奨 | 左下の装飾イラスト。縦横比を維持して収める |
| `input-frame.png` | 600 × 90 | 中央を透過にする | 実物の入力欄の周辺装飾。入力文字・カーソル・標準の入力背景はそのまま残る |
| `button.png` | 440 × 78 | 角・外周は透過可 | 戻る・参加・右下の補助ボタンに共通で使う背景。各ボタンの枠へ合わせて表示する |

`button.png` は大きさの異なる複数ボタンで共有するため、固定の文字・アイコンや、伸縮に弱い細かな装飾を焼き込まないでください。標準ボタンの文字色はそのまま使うので、明暗差を確保してください。

個別形状にする場合は、次のPNGを置くだけで該当ボタンを上書きできます。コード修正は不要です。個別PNGがないボタンは共通の `button.png` を使い、両方なければ標準のボタン背景を使います。

| 個別ファイル | 推奨サイズ（px） |
|---|---:|
| `button-back.png` | 195 × 60 |
| `button-join.png` | 440 × 78 |
| `button-unload.png` | 205 × 35 |
| `button-download.png` | 205 × 35 |
| `button-restore.png` | 205 × 35 |

文字・ホスト名・人数・地域・チャットタイプ・通知数・バージョン・チェック状態・カーソルは画像へ描き込まないでください。これらはUnity側で動的表示します。

背景と左上のShellロゴは既存タイトル画面の素材を再利用します。専用ロゴを新たに複製・改変していません。

## 操作部分との分離

- `EnterCodeManager` の `TextBoxTMP`、参加・戻るボタン、検索結果テキストは元の実物を利用します。
- サーバー選択、検索チェックボックス、前回のコード復元、MOD無効化、ホスト版ダウンロードは既存のShell拡張の実物を利用します。
- コールバック、キー処理、入力欄のフォーカス、参加可否、通信・認証処理は画像側にありません。
- 画像オブジェクト名は `CodeEntryArt_panel`、`CodeEntryArt_illustration`、`CodeEntryArt_input-frame`、`CodeEntryArt_Back/Join/Restore/Download/Unload` です。画像にはColliderを追加しません。
- ボタン画像を設定した場合も有効・無効とハイライトは標準ボタンの状態に追従します。参加条件を画像側で決定しません。
- 画面の基本座標は1672×941。位置と枠サイズの定義は `Modules/MainMenu/SeasideCodeEntryLayout.cs` に集約しています。PNGを推奨サイズ・比率で作成すれば座標修正なしで差し替えられます。

## 表示内容

「ホスト」「最大人数」「地域」「チャットタイプ」の値は元の検索結果テキストを移動して表示します。検索結果がない場合や標準処理がフィールドを非表示にしている場合に、仮の値を埋めません。

右側のサーバー選択ボタンには、既存のShellサーバー選択をそのまま使います。「地域」の検索結果表示と「選択中サーバー」は異なる場合があるため、別の操作領域として配置しています。チャットタイプは標準と同じ情報表示で、独自の選択・変更処理は追加していません。

## 読み込みの上限・失敗時

PNGのみ、1ファイル16MiB以下、幅・高さは各4096px以下です。画面1回の読み込みで画像合計32MiB、合計16777216ピクセルまでです。同じボタンPNGを複数回デコードしません。

存在しない・破損・サイズ超過の場合は、その画像だけを省略し、仮表示と標準コントロールを維持します。`SEASIDE_CODE_ENTRY_ART_UNAVAILABLE` を該当ファイル種別につき1回記録します。

## 確認手順

1. まずPNGなしでコード入力、貼り付け、参加可否、検索、戻る・ESCを確認する。
2. PNGを上記フォルダに保存し、コード画面を開き直す。
3. 入力文字や警告が隠れないこと、参加ボタンが無効のときクリックできないことを確認する。
4. サーバー一覧がパネルの前に表示され、選択後に閉じることを確認する。
5. 参加失敗のメッセージ、繰り返し開閉、4:3・16:9・横長・縦長ウィンドウを確認する。

この手順書は画像差し替え用です。実際のAmong Us上の見た目・入力・通信の成功は、自動テストのみでは確認済みになりません。
