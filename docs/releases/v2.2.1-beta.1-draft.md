# TOH-Shell v2.2.1β リリースノート（下書き・未公開）

製品バージョン：`2.2.1-beta.1`
統合元：提供ZIP名 **4.40.02** と追加提供の **main ZIP**。旧ZIP内の表示値は4.40.00α、mainは4.40.02αで、ZIP名だけでは時系列を確定できません。履歴がないためmain固有差分は別に追跡しています。4.40.01を統合済みとは扱わず、保存済み4.40.00と現在のShell実ソースを比較して累積変更を選択的に取り込みました。
これはローカル開発版の変更記録です。一般公開・ゲームへのDLL配置・実機検証は未実施です。

## ソースへ反映した内容

- マッドサイコ：タスク達成・反射可能状態をプレイヤーごとに管理。反射処理を共通化し、能力が未解放なら相手の通常能力を妨げないよう調整。既存の`Madpsycho`識別子、Config ID `22800`、翻訳キーを維持しました。
- ダブルキラー：ファントム能力の使用回数、ベント・サボタージュ設定、クールダウン復元を整理。通常キルを維持し、FixedUpdateごとの遅延処理生成と会議後の古い状態復帰を防止。使用回数の設定上限は14です。
- ハンター：対象参照と役職色の状態を所有者ごとに確認。共通の攻撃判定を通し、攻撃不成立時のテレポート・速度上昇・暗転を抑制。会議・死亡・役職破棄時に状態を解除し、遅延処理の世代を確認します。
- ヘイトキラー：投票除外数を所有者ごとに保持。Shellの最終投票力（マーシャルの補正を含む）を使用し、再集計による二重加算を防止します。
- 複数役職からのマッドサイコ反射呼び出し、プロフェッショナルの能力クールダウン設定、マリオの専用キルクールダウン値を調整しました。
- Shell独自の既存修正・ID・翻訳・リソース・クレジットと、メニュー・AI・自然災害・マッチメイキングの実装を維持しています。

## 今回追加した調整と未確認事項

- Mira HQのベント制限：偽の掃除情報を送る方式を採用せず、ホストのネイティブ移動処理を通常の退出へ変換し、既存の退出RPCで補正する方式を実装しました。Standard/Mira/ホストだけに適用。Vanillaでは矢印が残り、禁止経路の操作時に移動元から退出する場合があります。IL2CPPへの実際のパッチ適用とVanilla同期は実機未確認です。
- ハンターの複数人割り当てを1～15人に対応。暗転を所有者ごとの参照管理へ変更し、一方の解除で他方の効果や他役職の暗転を消さないようにしました。対象・速度・クールダウンは所有者別です。複数人での追跡・勝利・Vanilla同期は実機未確認です。
- Android専用認証・互換ヘルパー、ZIP内の一時ファイル・バックアップ・起動スクリプトは取り込みません。
- ノヴァ（Nova）：追加提供mainの公式実装をローカル統合。ファントムボタンでチャージ、移動操作で照準、再押下で方向確定して発射します。Role588/Config992900/From.UchuAddonを登録。以前取り消したペット発射版は使用していません。実機未検証です。
- Novaの複数所有者の描画設定、会議・死亡・破棄での速度復元、描画準備前の攻撃抑止、細幅ビームの表示上限・壁際の表示/判定、同一ビームから防御対象への連続攻撃を調整しました。詳細は`docs/ports/Nova-official-main.md`。
- main固有差分から、猫の既存陣営保護、マッドカインドの情報非公開、アサシンの会議競合回避、アーネストウルフのキル帰属、マッドパラサイトの最後のインポスター保護、アライグマ親子の会議前処理、プロフェッショナルの通報制限期間、ターンコートのdesync情報、設定読み込み失敗の復旧を選択統合。遅延したゴースト役職再設定が勝利確定後に走ることも防ぎます。
- ダブルキラーのベント中に失われる能力クールダウンを補正。古い補正タイマーが新しい状態を消さないように世代とリビジョンを確認します。
- mainのUI一括置換・新AI・統計の常時ON化・新しい通信監視や全送信抑制・Sniperのネットワーク銃表示などは一括導入していません。詳細は今回のUPSTREAM-DECISIONS.mdに記録します。
- 内部バージョン`4.00.40.00`、RPC ID、既存Role ID・Config ID・Option IDは維持。旧MODクライアントと混在する場合の互換性は実機未確認です。
