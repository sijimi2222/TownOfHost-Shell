# TownOfHost-Shell v2.2.4

Windows版の正式リリースです。

## v2.2.3からの主な変更

- Novaのビーム表示、Airshipでの射程、表示に使うダミーの生成・後片付けを改善しました。
- ゲーム内HUDのヘッダーと役職ガイドの表示を調整し、STREAM設定画面をShellのタイトルUIに合わせました。
- 陰陽師の対象役職判定、AmateurTellerのゲッサー用役職名判定、Expressの役職解除時の速度復元を修正しました。
- ロビー退出時の終了処理を整理し、前の部屋の処理が次の部屋に残らないよう改善しました。
- 対応するGoogle連携設定がある環境では、YouTube公式APIからライブコメントを表示できます。OAuthのクライアント設定や認証情報は配布物に含みません。YouTube投票・Kick・参加希望受付は無効です。

## ダウンロード

- **Steam版** — `TownOfHost-Shell_steam_v2.2.4.zip`
- **Epic版** — `TownOfHost-Shell_epic_v2.2.4.zip`
- **DLL単体** — `TownOfHost-Shell.dll`。対応するBepInEx環境を導入済みの方向けです。

Steam版・Epic版のZIPには、同一のTOH-Shell DLLが入っています。
