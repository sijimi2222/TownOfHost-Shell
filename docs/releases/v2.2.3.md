# TownOfHost-Shell v2.2.3

## UIの変更

- オンラインメニューをShellの夕暮れデザインに統一しました。ゲーム作成・コード入力・戻るは既存の処理へ接続しています。
- コード入力画面をShell専用UIに変更しました。ルームコード入力・貼り付け・サーバー選択・参加処理などは既存機能を利用します。
- オンラインメニューとコード入力画面の装飾をPNGで差し替えられる構造にしました。画像未設定時も仮パネルで操作できます。
- ゲーム作成への移動時にオンラインUIが再表示され、操作不能になる問題を修正しました。

## 安定性の改善

- 通信送信が失敗した場合にも、送信バッファを一度だけ解放するよう改善しました。
- 外見同期に失敗した場合に、一時的に変更した外見情報を復元するよう改善しました。
- 古いダミー生成の遅延処理が、次のセッションや新しい生成処理へ干渉しないよう確認を追加しました。
- 自動ロビー復帰は、同じ終了画面・セッションが有効な場合だけ実行するよう改善しました。
- キャンセル済みの遅延処理と、無効なマップ読み込みハンドルの扱いを改善しました。

## 軽量化

- 遅延処理がないフレームでの不要なメモリ割り当てを削減しました。
- 閉じたドロップダウンのUI探索と、記録上限到達後の診断処理を削減しました。

## 維持する機能と注意事項

- 現在の開発版のhamo・Pko由来役職、Shell版デストロイヤー、Nova、エリミネーター、AI・自然災害・マッチメイキングなどの実装と設定を維持しています。
- Role ID・Option ID・RPC番号・Fork ID・hamo由来の内部通信バージョンは変更していません。MOD同士のビルド照合にはShell v2.2.3を使用します。
- 今回の安定性改善は、クラッシュやホスト切断のリスク低減を目的としています。発生原因をすべて特定したものではなく、完全な解消を保証するものではありません。
- 直前の安定化版v2.2.2のオンライン画面・コード入力・ゲーム作成／参加・試合動作は管理者の実機確認済みです。全役職・長時間負荷・すべての端末の動作確認を意味しません。
- Steam版・Epic版での実機確認は管理者から問題なしとの報告を受けています。Codexによるゲーム起動は行っていません。VanillaのSwitch・スマホを含む全組み合わせや長時間負荷は未確認です。
- 非公開の二つ名実装は今回復元・追加していません。現在の開発ソースに含まれない機能の動作は保証しません。

## 画像の差し替え

`BepInEx/config/TOH-Shell/MainMenu/` 配下のPNGを利用します。推奨サイズ・ファイル名は次を参照してください。

- [オンラインメニュー用画像](../ui/online-menu-artwork.md)
- [コード入力画面用画像](../ui/code-entry-artwork.md)

Steam版・Epic版ZIPには同一のTOH-Shell v2.2.3 DLLを含めます。既存のMOD設定・ログ・個人用データは同梱しません。

## 配布ZIPの整理

- 既存v2.2.2のSteam ZIPに含まれていたx86ローダー／ランタイムを、現在のSteam本体（x64）に合わせたx64構成に更新しました。既存Epic版のx64構成は現在のSteam実行環境の主要DLLとSHA-256が一致します。
- ZIPの多重フォルダを解消し、古いMOD設定・ログを除外しました。Steam版とEpic版には同一のv2.2.3 DLLを収録します。
