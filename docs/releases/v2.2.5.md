# TownOfHost-Shell v2.2.5

Windows版の正式リリースです。

## v2.2.4からの主な変更

- **新役職 マッドアルターネイト**を追加しました。タスク完了後に自分へ投票すると保護対象を選べます。選んだ相手が次の会議までにキルされそうになったとき、自分が身代わりとなり死因が「殉死」になります。通常・ショート・ロングタスク数はそれぞれ0〜10で設定できます。
- **タイガー**がルーラーやチューナーのキルクール補正中も捕食できるようにしました。捕食された死体は自動通報や会議表示から除外します。
- **ロビーのバグ報告フォーム**を追加しました。日本語入力に対応し、任意で直近の試合の診断ログを添付できます。送信前は添付のオン・オフ、投稿後は添付の有無が表示されます。送信を利用するには運用者の受付設定が必要です。
- **配信コメント枠**を、タスク画面の表示中はドラッグで動かせないようにしました。
- **軽量化**。ノヴァの待機中の処理と、MOD全体で使うプレイヤー一覧の取得時のメモリ確保を減らしました。

## ダウンロード
