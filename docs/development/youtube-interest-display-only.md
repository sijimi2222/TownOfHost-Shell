# YouTube参加希望の表示専用化（ローカル開発版）

バージョン2.2.3を維持。公式API受信基盤へ移行済み（詳細は [公式API設計](youtube-official-api.md)）。認証UI・安全なトークン永続化・実通信検証は未完了。バックエンドは未構築。非公開API/HTML取得コードは撤去し、フォールバックしない。

YouTubeマップ投票は廃止。旧設定ID1400171とコメント必須参加のID1400164は予約・非表示とし、保存値がONでも投票・参加制限・受付開始に使わない。直接呼出しも無作用。通常のマップ選択・ランダム選択や、別用途のBan等は維持する。

参加希望の公開利用は規約確認待ち。現在は `ParticipationPolicyReviewed=false` の内部ゲートで実コメントからの受付を停止する。模擬テストに限って受付を有効化する。

規約確認・認証UI実装後の予定：参加希望者一覧には、今回受け付けた人数とYouTube表示名だけを表示する。配信URLと既存の参加希望キーワードを設定し、コメント表示をONにした上で、参加希望者一覧の「受付開始」を選ぶ。キーワード後のゲーム内名は不要。受付・一覧操作だけで追加のコメント取得は始めない。

同一チャンネルは重複せず、同名別チャンネルは別件。内部チャンネルIDは表示・ログに出さない。上限200件、30件ずつのページ表示。受付終了では一覧を残し、希望者一覧の初期化では一覧だけを消去する。「コメント枠の位置を戻す」は従来どおり別機能。

URL変更・切断・終了で不要な受付情報を消す。受付開始・終了・初期化時は世代を切り替え、旧キューや処理中の応答から登録が復活しないようにする。接続時の履歴は複数応答にまたがっても参加希望にしない。公開時刻と受付開始・初期化の時刻も照合する。

コメントに由来するKick・入室資格判定・ゲーム内名照合・参加済み振分けを撤去した。自動入室も追加していない。ホストの手動判断と他の通常ロビー処理を置き換えない。

模擬コメント、HTTPハンドラー、合成Unityを使って検証する。実ライブ取得・実ゲームUI・実機での操作は別途未確認。公式方式の失敗時も旧方式へ戻らない。認証未設定ではHTTPリクエスト自体を開始しない。
